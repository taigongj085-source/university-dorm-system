技术要求：
springboot4
mysql8
mybatis-plus
redis
thymeleaf
优先使用hutool工具类库
spring security实现认证、简单授权功能

单体架构

需求：
大学宿舍管理系统是一个基于springboot4的单体架构项目，用于大学宿舍的管理操作。
resource/static 静态资源
resource/templates 模板
resource/templates/back 管理后台
resource/templates/front 网站前台页面

管理后台功能：
1. 用户登录（管理员 / 辅导员）
2. 楼栋管理、房间管理、床位入住 / 退宿
3. 学生管理、教师管理、账号管理
4. 公告管理
5. 报修工单处理
6. 请假 / 晚归审核
7. 访客登记管理
8. 卫生检查录入
9. 系统设置

前台功能：
1. 用户注册、登录
2. 个人资料与修改密码
3. 我的宿舍（床位图、室友、卫生分）
4. 公告浏览与详情
5. 在线报修与进度查询
6. 请假 / 晚归申请与结果查询
7. 访客登记
8. 卫生检查记录查询

SQL 脚本：docs/schema.sql（含 CREATE DATABASE / USE 与种子数据）
静态页面原型：dorm-ui/（可直接浏览器打开预览）
启动说明：见 README.md
